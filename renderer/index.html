          更新

          目前是版本 。按「檢查更新」才會連到 GitHub 看有沒有新版，平常不會自己連網路。

          開啟 PDF 時

          適用於在檔案總管連點兩下和按「開啟」。把檔案拖進視窗一律是新分頁。已經開著的檔案會直接跳過去，不會再開一份。

          設為預設 PDF 程式

          Windows 不讓程式自己把自己設成預設，要由你確認一次。設好之後，在檔案總管連點兩下 PDF 就會用本程式開啟。

          1. 在打開的設定畫面按「.pdf」那一列。沒看到的話，在上方的搜尋框輸入 .pdf。
          2. 選「PDF閱讀列印」，再按「設定預設值」。
          .pdf PDF閱讀列印

          另一種方式：在任一 PDF 上按右鍵 →「開啟檔案」→「選擇其他應用程式」→ 選「PDF閱讀列印」→ 按「一律」。

          清單裡找不到本程式的話，表示這份不是用安裝程式裝的。

          解除安裝

          Windows「設定」→「應用程式」→「已安裝的應用程式」→ 找到「PDF閱讀列印」→「解除安裝」。不會動到 PDFgear；如果當時預設是本程式，下次開 PDF 時 Windows 會問要用什麼開啟。

          把安裝程式給別人時

          第一次執行會出現藍色的「Windows 已保護您的電腦」，因為這個程式沒有購買數位簽章。按「其他資訊」，再按「仍要執行」就可以繼續。
